## 📌 Основні можливості

- Презентація міста, його історії та культурної спадщини.

### Екскурсії

- Інформація про тривалість, вартість та зміст екскурсій.
- Фотогалереї.

### Новини та події
- Публікація новин туристичного центру.

- Каталог готелів та інших місць проживання.
- Адреси, описи, контакти, ціни та графіки роботи, якщо ці дані внесені.
- Посилання на карти та телефонні дзвінки.

## 🛠️ Технології

## 🔥 Firebase

Сайт використовує Firebase для зберігання контенту та завантаження опублікованих записів.

Основні колекції Firestore:

| Колекція | Призначення |
|---|---|
| `places` | Туристичні пам’ятки та цікавинки |
| `tours` | Екскурсії та туристичні маршрути |
| `news` | Новини й оголошення |
| `food` | Заклади харчування |
| `stay` | Готелі та місця проживання |
| `siteContent` | Тексти головної сторінки, інформація про місто, контакти та маршрут до Звягеля |

Для відображення записів на публічному сайті використовується поле `published`. На сайті відображаються записи, для яких значення цього поля дорівнює `true`.

## 🖥️ Адміністративна панель

Адміністративна панель призначена для керування вмістом сайту без ручного редагування HTML.

Залежно від налаштованих можливостей панелі адміністратор може:
- Додавати, редагувати та видаляти записи.
- Публікувати або приховувати матеріали.
- Додавати фотографії та їхні URL-адреси.
- Редагувати тексти головної сторінки й контактні дані.
- Оновлювати інформацію про екскурсії, пам’ятки, новини, заклади харчування та проживання.

**Безпека:** доступ до записів у Firestore визначається правилами Firebase, а не лише перевіркою в інтерфейсі адміністративної панелі. Необхідно налаштувати автентифікацію та правила доступу так, щоб лише уповноважені адміністратори могли змінювати дані.
